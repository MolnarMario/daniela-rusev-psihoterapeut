# Daniela Rusev, site de prezentare

Site static pentru cabinetul de psihoterapie al Danielei Rusev (Drumul Taberei 29, București). Nu are build și nici framework. Fiecare variantă e un singur fișier HTML cu CSS inline.

- `index.html` e varianta principală. Respectă ghidul anti-"look de AI": hero asimetric, paletă luată din fotografie (bleumarin, roșu de mac, prună), Fraunces cu Instrument Sans, fără carduri decorative.
- `varianta-libera/index.html` e varianta fără restricții de design: temă întunecată, gradienți, carduri de sticlă, animații la scroll.
- `img/` conține fotografia în WebP și JPG, la 480 și 900 px lățime, plus `og.jpg` pentru preview-ul pe rețele sociale.
